# コーディング規約（必須事項）

1. **TypeScriptベースでの実装**
   - すべてのフロントエンドコードは TypeScript (`.ts` / `.tsx`) で記述し、型安全性を確保すること。

2. **TypeDocコメントの必須化**
   - クラス、インターフェース、型定義、関数、Reactコンポーネント、変数、定数、引数 (`@param`)、戻り値 (`@returns`) には**必ず TypeDoc 形式（`/** ... */`）のコメント**を記述すること。

3. **処理内容・設計理由（What / Why）のコメント必須化**
   - 各処理ブロックにおいて、「何をしているか（What）」だけでなく「なぜこの処理が必要か（Why）」を、後から確認しやすい日本語コメントとして必ず残すこと。
