# 通常ゲオの取扱商品・UIの再点検（2026-10-19）

本書の店舗数・テスト数はPC専門4チェーン追加前の調査時点の記録です。現在の収録数・仕様は[SPECIFICATION.md](../SPECIFICATION.md)の4.1・11・12章を参照してください。

## 結論と取得経路

従来は通常ゲオにも `https://geo-mobile.jp/store/{5桁番号}.html` を使用し、「取り扱いサービス一覧」の携帯電話販売・中古パソコンを商品分類へ変換していた。このページは通常店に併設されたモバイル部門の案内であり、ゲーム等を含む店舗全体の販売品目ではない。`partial`と記録していたが、店舗カードではスマホ・PCだけが強調され、他の商品を扱わないように見える問題があった。

現在の公開DBは2,514ピン。通常GEOの看板を持つ682ピンのうち681がpartial、1がunverified。モバイルの看板を持つ130ピンはconfirmed 124・partial 6。複合店を含むため、取得元の店舗行数とは異なる。

店舗一覧は今後も公開されているゲオモバイルの全国一覧を利用する。一方、商品の取得元は通常店と専門店を分ける。

1. 通常店は `https://geo-online.co.jp/store/{5桁番号}/` の店舗名と「お取扱い品目」を照合する。
2. その中の「新品販売」「中古販売」のみを抽出する。レンタル・買取・通販ナビ・近隣店舗・無効表示の項目は対象外。
3. 「携帯電話 ※格安SIM即日開通のみ」は端末販売にしない。「家電 ※AV機器・アクセサリのみ」は生活家電の詳細分類にしない。「ゲーム」だけではレトロ・現行の両方を保証しない。
4. 通常店の全体情報が取得できない場合、過去に取得した全体情報があれば確認日付きで保持する。全体情報を狭いモバイル部門の情報で上書きしない。
5. モバイル部門しか確認できない通常店はpartialとし、詳細を閉じたスマホ表示でもその制限を常に案内する。ゲオモバイル専門店は従来のサービス欄で確認する。
6. 共通のメンテナンス・403・429等では、全店に同じ失敗要求を繰り返さない。1店舗だけの404や名称変更では他の全店の取得を止めない。

## 今回確認できた範囲と制限

通常サイトは、ブラウザーで詳細ページを開くと[公式メンテナンス案内](https://geo-online.co.jp/maintenance/index.html)へ転送された。HTTPでの直接取得も403だった。案内には10月17日21時から終了時期未定とある。

検索サービスに保存されている[ゲオおゆみ野店](https://geo-online.co.jp/store/02765/)・[ゲオ亀岡店](https://geo-online.co.jp/store/02403/)の公式ページの表示内容では、モバイル部門以外にゲーム・トレカの販売等を確認できる。新品携帯電話のSIM限定、家電のAV機器・アクセサリ限定という注意書きも確認した。一方、DVD・コミックのレンタルを販売へ転用してはならない。

検索側の保存内容を「本日全店を取得した最新データ」としてDBへ投入していない。既存の通常ゲオの販売品目を完全に補完できたわけではない。全店の最新販売品目の取得・本番DOMとの照合は、公式サイト復旧後の残作業である。

`scripts/geo_assortments.py`に取得元の分離・販売欄の解析・障害時の保持処理を実装した。公式表示の見出し・品目に基づく意味構造のfixtureで検証し、構造変更時は新たな確認成功として扱わない。実際の現行HTMLを取得できていないため、DOMへの適合を保証しない。復旧後のGitHub Actionsでも、構造と店舗名を照合できた情報だけを採用する。

ゲオおゆみ野店の実通信による試行では、修正後の処理もモバイルの出典へ戻り、`partial`・`pc_junk`を返した。全体確認への誤昇格や、未確認のゲーム等の推測追加はしていない。既存DBの品目は今回書き換えていない。

Python 18件・Node 18件と本番ビルドを確認。通常店の全体確認、SIM・AV限定、レンタル・買取の除外、店舗名・構造の相違、障害時の過去情報保持、専門店との区別、複合店で別店舗の根拠を混ぜない案内表示を検証した。

## UIの改善候補（未実装の提案）

優先度順。

1. **広域地図のロゴの重なりを減らす。** 縮尺に応じて店舗を件数のまとまりで表示し、近づくと個別ロゴに展開する。選択店を優先し、現在のロゴ枠の比率と配色は保つ。
2. **未確認店も検索できる選択肢を設ける。** 「確認済みだけ／未確認も含める」を選べると、ゲーム等が未確認の通常ゲオが検索から消える理由を理解しやすい。未確認を取扱ありと混同しない表示が前提。
3. **商品名の粒度を整える。** 公式の「中古パソコン」を「PC・ジャンク」という大きな分類だけで見せるとジャンク販売まで保証したように読める。店舗で確認できた具体的な品目と注意書きを先に見せ、検索用の分類と区別する。
4. **スマホの地図と一覧の高さを調整できるようにする。** 現在は44%で固定。短い画面・長い店舗名・注意書きではカード全体が収まりにくい。境界の調整や「地図を広く／一覧を広く」を用意するとよい。

今回の実装は商品情報の取得経路と、モバイル部門だけの確認を知らせる表示に限定した。上記のUI変更は提案であり、実装済みではない。
