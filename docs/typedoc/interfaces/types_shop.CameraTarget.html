Interface CameraTarget

地図カメラ（中心座標・ズーム倍率）の移動指示パラメータを保持するインターフェース。

【なぜこのインターフェースが必要か】 店舗リストのカードクリック、ヘッダーのプリセット地域ジャンプ、現在地ボタン押下など、 外部のUIコンポーネントから地図コンポーネント（Google Maps / Leaflet）に対して 視点移動（パン・ズーム）を安全かつ宣言的に要求するためです。 同一店舗・同一座標への連続クリック時でもReactの useEffect が状態変化を確実に検知できるよう、 リクエストごとにインクリメントされる更新シーケンス番号（seq）を内包しています。

interface CameraTarget {
    lat: number;
    lng: number;
    seq: number;
    zoom?: number;
}

seq

seq: number

同一座標への連続再ジャンプ要求を検知するための更新シーケンス番号。 座標やズーム値が直前と同一であっても、ユーザーが店舗カードを再度クリックした場合に useEffect によるカメラ移動・バルーン再展開処理を発火させるために呼び出し毎に加算されます。

zoom?: number

変更後の推奨ズームレベル（1〜20）。 省略された場合は現在の地図のズーム倍率を維持したまま中心座標のみをパン移動します。 店舗フォーカス時は一般に 15 または 16、広域エリアジャンプ時は 11〜13 が指定されます。
