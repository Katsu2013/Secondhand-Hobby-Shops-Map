Interface TravelModeInfo

アクセス手段（移動モード）のマスター定義および所要時間推計パラメータのインターフェース。

【なぜ推計パラメータが必要か】 地図画面内に表示される数百件の店舗すべてに対して毎回ルート検索APIを呼び出すと、 API課金枠の枯渇やレート制限エラーが発生します。そのため、画面内の全店舗に対しては 直線距離×迂回係数と平均速度モデルによるリアルタイム概算時間を常時表示し、 店舗をクリックした際に実ルート検索APIで確定値に更新するハイブリッド設計としています。
