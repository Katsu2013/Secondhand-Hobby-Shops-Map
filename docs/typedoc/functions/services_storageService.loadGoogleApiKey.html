Function loadGoogleApiKey

  • loadGoogleApiKey(): string

  • URLクエリパラメータ（?apiKey=... または ?key=...）、localStorage、 またはビルド時の環境変数（VITE_GOOGLE_MAPS_API_KEY）から Google Maps APIキーを取得します。

    【なぜこの優先順位にするか】

    1. URLパラメータ指定があれば最優先で localStorage に記憶させることで、初回1回リンクを開くだけでキー設定を完了できるため。
    2. ソースコード（GitHubリポジトリ）上に生のAPIキーをハードコードせず、ローカルの .env.local（Git管理外）や ブラウザの localStorage から安全に読み込めるようにするため。

    Returns string

    取得されたAPIキー文字列（未設定時は空文字列 ""）
